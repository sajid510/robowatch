# RoboWatch Roadmap

## Phase 1 — Foundation ✅
- Repository branding
- Documentation (15 docs + 8 architecture docs)
- Architecture diagrams (SVG)
- README with badges

## Phase 2 — Engineering ✅
- Testing (35+ pytest tests, offline-safe)
- Docker + docker-compose
- CI improvements (tests workflow, Python 3.10–3.12 matrix)
- Run modes: `--offline`, `--dry-run`, `--send`

## Phase 3 — Intelligence quality 🔜
- Embedding-based near-duplicate detection
- Feed-quality weighting
- Per-subscriber topic personalization
- `--since` backfill for past weeks

## Phase 4 — Distribution 🔜
- Render digest to GitHub Pages (static site)
- RSS-out feed for subscribers
- Webhook delivery for downstream automation
- Usage dashboard (stats.json-driven)

## Phase 5 — Community 🔜
- Public release polish
- Contribution guide adoption
- Template-ification (multi-digest configs)
